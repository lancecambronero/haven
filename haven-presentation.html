How it is built

Current prototype

  • One HTML file with inline CSS and JavaScript, no framework
  • Data-driven: services, team, values and industries come from arrays, so edits are easy
  • Pages switch with URL hashes such as #services
  • Only external call: Google Fonts

Not built yet

  • The inquiry form only shows the workflow; it sends nothing
  • Team photos are placeholders
  • Contact details are placeholders
  • No analytics, SEO setup or real separate URLs

The inquiry form is the conversion point

Fields are grouped as contact, business and support requirements, so each inquiry arrives qualified.
